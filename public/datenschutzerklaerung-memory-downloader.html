2. Allgemeines

Der Schutz Ihrer Daten ist mir wichtig. Die App Memory Downloader wurde so entwickelt, dass keine personenbezogenen Daten erhoben, verarbeitet oder übertragen werden.

Die App dient ausschließlich dazu, von Ihnen bereitgestellte Exportdateien (z.B. Snapchat Memories) lokal auf Ihrem Gerät zu verarbeiten und zu speichern.

3. Welche Daten werden verarbeitet?

Von Ihnen ausgewählte Dateien:

  • ZIP-Archive aus Snapchat-Datenexporten
  • Medieninhalte (Fotos, Videos)
  • JSON-Metadaten (Aufnahmedatum, Uhrzeit, Standortinformationen)

Metadaten aus den Exporten:

  • Erstellungsdatum und Uhrzeit von Medien
  • GPS-Koordinaten (falls im Export enthalten)
  • Dateinamen und interne Export-IDs

Die App verarbeitet keine Daten automatisch im Hintergrund und greift nur auf Dateien zu, die Sie explizit auswählen.

4. Wie werden die Daten verarbeitet?

  • Alle Daten werden ausschließlich lokal auf Ihrem Gerät verarbeitet
  • Es findet keine Übertragung an Server oder Cloud-Dienste statt
  • Es gibt keine Benutzerkonten und keine Anmeldung
  • Die App nutzt keine Analyse- oder Tracking-Dienste

Alle Konvertierungen, Sortierungen und Speicherungen erfolgen offline direkt auf Ihrem Gerät.

5. Weitergabe an Dritte

  • Es erfolgt keine Weitergabe Ihrer Daten an Dritte
  • Es werden keine Daten an Snapchat, Google, Apple oder andere Anbieter gesendet
  • Die App enthält keine Werbung und keine In-App-Tracker

6. Speicherung und Löschung

  • Gespeicherte Medien werden lokal auf Ihrem Gerät abgelegt
  • Sie können die gespeicherten Dateien jederzeit manuell löschen
  • Beim Deinstallieren der App werden alle App-Daten entfernt

7. Ihre Rechte

  • Einsicht: Alle Daten sind auf Ihrem Gerät sichtbar
  • Löschung: Sie haben jederzeit volle Kontrolle über Ihre Daten
  • Datenübertragbarkeit: Dateien liegen in gängigen Medienformaten vor

8. Sicherheit

  • Keine Internetübertragung sensibler Daten
  • Speicherung im Standard-Verzeichnis für Medien
  • Zugriff durch Fotos-App nach Wahl

9. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann bei Bedarf aktualisiert werden. Die jeweils aktuelle Version ist jederzeit über die verlinkte Webseite abrufbar.
