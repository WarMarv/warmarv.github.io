2. Allgemeines

Der Schutz Ihrer Daten ist mir wichtig. Die App Obzor wurde gezielt so entwickelt, dass keine personenbezogenen Daten an externe Server übertragen werden. Alle Daten werden ausschließlich lokal auf dem Gerät der Gemeindeleitung gespeichert.

Obzor dient der Erfassung der Gottesdienst-Anwesenheit von Gemeindemitgliedern sowie der Dokumentation des Predigt-Anfrage-Antwort-Ablieferungs-Workflows für Gemeinden — vollständig ohne Internetverbindung, Server oder Benutzerkonto.

3. Welche Daten werden verarbeitet?

Gemeindemitglieder:

  • Namen der erfassten Männer und Frauen

Anwesenheitsdaten:

  • Anwesenheit bzw. Abwesenheit pro Gottesdienst
  • Gründe für eine erfasste Abwesenheit
  • Datum und konfigurierbare regelmäßige Gottesdiensttage der Gemeinde

Predigt-Workflow:

  • Predigt-Anfragen, Antworten und Ablieferungen
  • Zuordnung dieser Vorgänge zu den erfassten Personen

4. Wie werden die Daten verarbeitet?

  • Alle Daten werden ausschließlich lokal auf dem Gerät in einer SQLite-Datenbank gespeichert
  • Es findet keine Übertragung an Server oder Cloud-Dienste statt
  • Es gibt keine Benutzerkonten und keine Anmeldung
  • Die App nutzt keine Analyse-, Tracking- oder Werbedienste

Ein manueller Export bzw. Import der Daten (z. B. zur Sicherung oder Übertragung auf ein anderes Gerät) erfolgt ausschließlich lokal über eine vom Gerät selbst gewählte Datei und wird zu keinem Zeitpunkt automatisch an Dritte übertragen.

5. Weitergabe an Dritte

  • Es erfolgt keine Weitergabe der erfassten Daten an Dritte
  • Es werden keine Daten an Google, Apple oder andere Anbieter gesendet
  • Die App enthält keine Werbung und keine In-App-Tracker

6. Speicherung und Löschung

  • Alle erfassten Daten werden lokal auf dem Gerät gespeichert, bis sie manuell gelöscht werden
  • Einzelne Personen, Anwesenheitseinträge oder Predigt-Vorgänge können jederzeit in der App gelöscht werden
  • Beim Deinstallieren der App werden alle App-Daten vollständig entfernt

Speicherort der Daten:

  • iOS: /Library/Application Support/de.gemeinde.gottesdienstAnwesenheit/
  • Android: /data/data/de.gemeinde.gottesdienst_anwesenheit/

7. Ihre Rechte

  • Einsicht: Alle erfassten Daten sind jederzeit in der App einsehbar
  • Änderung: Erfasste Daten können jederzeit in der App korrigiert werden
  • Löschung: Die Gemeindeleitung hat jederzeit volle Kontrolle über die Daten und kann diese löschen

Da die Daten ausschließlich lokal gespeichert werden, liegt die vollständige Kontrolle bei der Person, die das Gerät verwaltet.

8. Sicherheit

  • Keine Internetübertragung der erfassten Daten
  • Die SQLite-Datenbank wird durch das Betriebssystem geschützt
  • Nur die App selbst kann auf die gespeicherten Daten zugreifen
